# Round-bell multi-fidelity calibration

## Status

The two-stage optimizer remains a proposed architecture only. This diagnostic
compares the current axisymmetric fast solver with the direct cylindrical
vector-FEM reference on a controlled local sample. It does not enable a
production shortlist and does not change the production objective.

## 1.2.182 cross-solver modal association probe

- 30 deterministic circular geometries are generated by small perturbations of
the three interior meridional profile knots around the same reference bell.
- Ellipticity is exactly 1.0; material preset and 15-node meridional mesh are
identical between solvers.
- Fast path: `InternalModalSolver`, eight modes, with outer-wall modal traces
captured.
- Reference path: direct cylindrical vector FEM, harmonic block `m=0`, eight
modes, same meridional mesh, with outer-wall traces exported.
- Modes are associated using `trackModalFamilies`: sign-invariant outer-wall
radial/axial displacement-shape similarity, with frequency used only as a
weak tie-breaker. The matched reference modes are reordered into fast-family
order before comparing the first five family frequencies and frequency-shape
objective ranking.
- The probe reports minimum/mean trace similarity, matched-family frequency
difference, ambiguous candidate count and Spearman rank correlation.

The probe is reproducible via `multifidelity_calibration_probe`. Its output
includes every candidate row so that changes can be audited. The candidate
set is local and intentionally modest; it is not representative of the full
optimizer search domain.

## Observed result in 1.2.182

The 30-case run completed, but **none of the 30 assignments met the provisional
minimum trace-similarity threshold of 0.75**. The minimum similarity across
matched modes ranged from 0.136 to 0.497; the mean of per-candidate mean
similarities was 0.810. Several candidates produced large matched-family
frequency errors (maximum 102.66%). The all-candidate Spearman correlation of
the provisional shape-reordered objective scores was 0.679. Because all
candidates are flagged ambiguous, that correlation is descriptive only and
must not be used to justify a shortlist.

The existing `trackModalFamilies` routine returns a complete assignment even
when an individual match has weak shape evidence. The probe therefore applies
an explicit diagnostic rejection rule: `minimum_similarity < 0.75` marks the
whole candidate assignment ambiguous. This is a conservative audit threshold,
not a calibrated physical constant.

## Interpretation limits

1. The association uses outer-wall traces, not a common full-volume mass inner
product. In this run every candidate failed the provisional trace-similarity
gate. Similar boundary motion is evidence for a candidate association, not
proof that the complete eigenfields or modal subspaces are equivalent.
2. A single eigenvector trace is not sufficient for a near-degenerate
cosine/sine pair. Such cases must be compared as a subspace, and ambiguous
assignments must not be promoted to production.
3. The comparison isolates `m=0`. It does not include nonzero circumferential
harmonics or establish the complete physical acoustic spectrum.
4. Only frequency ratios are compared. The fast and vector solvers' current
amplitude fields do not yet have a validated common physical meaning.
5. The 30 cases are local perturbations, not a broad coverage of the search
space. No generalization or shortlist-recall claim follows from this sample.
6. The clapper parameters remain uncalibrated and are not used here.

## Required next work

- Inspect candidate-level results, especially low-similarity and ambiguous
assignments. Do not hide failed associations by dropping them from statistics.
- Extend matching to near-degenerate two-dimensional families using a common
boundary-trace subspace metric; verify against full-volume mass-weighted
similarity when both fields are available on compatible meshes.
- Expand the deterministic geometry set across the intended optimizer domain,
including profile-shape extremes and constraint boundaries.
- Measure shortlist recall of accurate top 5% and top 10%, not only global
Spearman correlation. Keep every ambiguous or unpaired candidate in a safe
fallback pool rather than discarding it.
- Only after the family correspondence is validated should matched-family
frequency scores be considered for screening. Amplitude/clapper terms require
a separate semantics and calibration audit.

Provisional promotion hypotheses remain: Spearman rho >= 0.90, matched-family
frequency error <= 3%, and >=95% recall of accurate top candidates. These are
not acceptance results and must be validated on a larger, domain-representative
set with uncertainty reporting.

## Production policy

`western_five_partial` remains the production objective. No multi-fidelity
shortlist is enabled. The direct cylindrical path remains a calibration
reference in this probe. The clapper objective remains experimental and is
not promoted.


## 1.2.183 boundary-trace subspace primitive

A new `boundaryTraceSubspaceSimilarity` diagnostic compares rank-1 or rank-2
subspaces formed from flattened radial/axial outer-wall traces. It orthonormalizes
each supplied basis and returns the minimum principal-angle cosine. The result is
invariant to sign, scale, and orthogonal rotation of the basis, which addresses
the arbitrary basis orientation of a two-mode near-degenerate eigenspace. Invalid,
rank-deficient, mismatched, or unsupported-rank inputs return `-1`.

This primitive is deliberately not yet used to reorder modes in the optimizer or
to certify fast-to-accurate cross-solver matches. It currently has synthetic
contract coverage only. The next validation must construct physically identified
near-degenerate groups, compare the boundary metric with full-volume
mass-weighted subspace overlap on compatible accurate FEM fields, and then rerun
the 30-case probe. A boundary metric that is rotation-invariant is not, by itself,
proof that it preserves physical modal-family identity. No screening or candidate
rejection is enabled in 1.2.183.

## Stage 6 — full-volume meridional cross-match (2026-11-10)

The 61-case probe's all-ambiguous result was revisited with a different matching
contract. The new research executable compares the first five legacy meridional
modes against up to eight direct cylindrical `m=0` candidates using a rectangular
one-to-one assignment and full-mesh radial/axial displacement overlap weighted
by direct FEM diagonal row-sum mass weights. It explicitly verifies the common
mesh-node ordering after mm-to-SI conversion. Azimuthal DOFs are excluded because
they have no legacy meridional counterpart; the metric is a lumped-mass
approximation, not a consistent-M inner product.

Results: 61/61 geometries, 305/305 first-five matches, minimum overlap
0.999999999999, maximum relative frequency difference `8.29e-13`. On the first
ten geometries, 23-node and 31-node meshes each produced 50/50 matches, with
minimum overlap at least `0.999999999999` and maximum frequency differences below
`7.55e-13`.

This suggests the earlier 8-by-8 boundary-trace assignment was allowing higher
legacy modes to compete with the first five target modes, or otherwise suffering
from boundary-trace ambiguity. The result is promising but not a promotion gate:
consistent-mass comparison, near-degenerate rank-2 subspaces, broader refined-mesh
coverage, and shortlist-recall analysis remain required. The production objective
and optimizer path remain unchanged. See
[`ROUND_SOLVER_FULL_VOLUME_CROSSMATCH_STAGE6.md`](ROUND_SOLVER_FULL_VOLUME_CROSSMATCH_STAGE6.md)
for method, limitations, detailed results, and reproduction commands.
