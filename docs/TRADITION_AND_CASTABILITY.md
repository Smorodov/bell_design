# Tradition, geometry and castability

## European / Western

Текущий западный reference profile использует conventional low-partial target. Это отдельный tuning profile, не универсальный закон для всех колоколов.

## Russian Orthodox

Orthodox profile остаётся геометрическим и сравнительным prior. Один universal modal recipe для всех русских колоколов не заявляется.

## Chinese zhong

Chinese profile теперь должен рассматриваться совместно с `research/chinese_bell/docs/CHINESE_BELL_ACOUSTIC_CANON.md`. Геометрический prior сам по себе не является физическим двухтональным zhong.

Минимальная физическая модель должна учитывать non-axisymmetric/elliptical geometry, две strike conditions, modal-family splitting и разные excitation patterns.

## Castability

Current checks are intentionally coarse:

- positive wall thickness;
- reasonable thickness ratio;
- sampled wall-thickness gradient;
- inner-surface validity;
- Q4 Jacobian/element quality.

Mold filling, feeding, gating, solidification and thermal casting remain outside the project.
